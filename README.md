### 🧑‍💻 学生 A: P1_Harmonic_Oscillator (简谐振子与能量守恒)
- **物理背景**: 简谐振子是最基础的保守系统。其运动方程为 

$$\frac{d^2x}{dt^2} = -\omega^2 x.$$ 

为了方便，我们取 $\omega=1$ 。写成一阶方程组为：

 $$\frac{dx}{dt} = v, \frac{dv}{dt} = -x.$$ 

该系统的总能量 $E = \frac{1}{2}v^2 + \frac{1}{2}x^2$ 应当随时间守恒。不同数值方法会导致能量随时间发生不同形式的漂移，这是数值积分最本质的缺陷之一。

- **目录**: `lab1_core/P1_Harmonic_Oscillator/`
- **任务**:
  1. 补全前向欧拉法 (`euler_step`) 和四阶龙格-库塔法 (`rk4_step`)。
  2. **误差阶验证**：分别取步长 $h = 0.1, 0.05, 0.02, 0.01$ ，计算 $T=10$ 时刻的全局误差。在双对数坐标系（log-log）下绘制误差随步长变化的图，拟合斜率，验证 Euler 为 $\mathcal{O}(h)$ ，RK4 为 $\mathcal{O}(h^4)$ 。
  3. 计算简谐振子的系统能量，对比两种方法在长时间演化中的能量漂移（思考：为什么 Euler 的能量是持续增长而不是随机涨落？）。
  4. 绘制相图（x-v平面）与能量变化图。
  5. 确保通过 `test_p1.py` 测试。

### 🧑‍💻 学生 B: P2_Lorenz_Chaos (洛伦兹吸引子与 AI 代码审查)
- **物理背景**: 洛伦兹系统是大气对流的简化模型，展示了确定性系统中的混沌现象（即蝴蝶效应：对初值极度敏感）。其方程组为：

 $$ \frac{dx}{dt} = \sigma(y - x) $$

 $$ \frac{dy}{dt} = x(\rho - z) - y $$

 $$ \frac{dz}{dt} = xy - \beta z $$

经典参数取值为 $\sigma=10, \rho=28, \beta=8/3$ 。
- **目录**: `lab1_core/P2_Lorenz_Chaos/`
- **任务**:
  1. 审查 `p2_lorenz.py`，找出并修复 AI 留下的**两处数学符号陷阱**（这些错误会导致吸引子崩溃）。
  2. 使用 `solve_ivp` 求解系统，绘制 3D 轨迹图。
  3. 引入极小扰动 ( $10^{-5}$ )，展示“蝴蝶效应”（轨迹的指数分离）。
  4. 确保通过 `test_p2.py` 测试。

### 🧑‍💻 学生 C: P3_Kepler_Orbit (开普勒轨道与守恒量)
- **物理背景**: 行星绕恒星运动可简化为中心力场下的二体问题。运动方程为 

$$\frac{d^2\mathbf{r}}{dt^2} = -\frac{GM}{r^3}\mathbf{r}.$$

令 $GM=1$ ，在一阶形式下有：

$$\frac{d\mathbf{r}}{dt} = \mathbf{v}
, \frac{d\mathbf{v}}{dt} = -\frac{\mathbf{r}}{r^3}.$$

该系统具有重要守恒量：系统能量 $E$ 、角动量 $\mathbf{L} = \mathbf{r} \times \mathbf{v}$ ，以及指示椭圆长轴方向的龙格-楞次矢量 $\mathbf{A} = \mathbf{v} \times \mathbf{L} - \frac{\mathbf{r}}{r}$ 。
- **目录**: `lab1_core/P3_Kepler_Orbit/`
- **任务**:
  1. 补全引力场中的运动方程（`kepler_deriv`）。
  2. 计算角动量与龙格-楞次矢量（Runge-Lenz vector），验证其在 RK45 下的守恒性。
  3. 使用 `solve_ivp` 绘制椭圆轨道。
  4. 确保通过 `test_p3.py` 测试。

### 🚀 共同挑战 (Bonus): Van_der_Pol (刚性方程与极限环)
- **物理背景**: 范德波尔振子是一个具有非线性阻尼的振荡器，方程为 $\frac{d^2x}{dt^2} - \mu(1 - x^2)\frac{dx}{dt} + x = 0$
。当阻尼参数 $\mu$ 较大（如 $\mu=50$）时，系统在相空间中呈现快慢尺度混合的“弛豫振荡”，导致微分方程变得非常“刚性”（Stiff）。此时普通的显式数值方法（如 RK45）需要极小的步长才能稳定，计算效率急剧下降，必须使用隐式求解器（如 Radau 或 BDF）。
- **目录**: `lab2_bonus/`
- **任务**:
  1. 将二阶方程降阶为一阶方程组，并补充 `vdp_deriv` 函数计算状态导数。
  2. 在高阻尼 ( $\mu=50$ ) 时，对比显式算法 (`RK45`) 和隐式算法 (`Radau`/`BDF`) 的计算效率（通过查看 `sol.nfev` 即函数调用次数）。
  3. 绘制极限环相图。
